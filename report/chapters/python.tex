\section{Calling the Model from Python}
\label{sec:python}

Small Python scripts are used to interface with the MiniZinc model. The model is
loaded through \texttt{minizinc-python} and associated with the Gecode solver:

\vspace{0.5cm}
\begin{lstlisting}[language=Python]
model    = Model("model.mzn")
solver   = Solver.lookup("gecode")
instance = Instance(solver, model)
\end{lstlisting}
\vspace{0.5cm}

The scripts then assign concrete values to the MiniZinc parameters and start the
solving process:

\vspace{0.5cm}
\begin{lstlisting}[language=Python]
instance["n_boxes"]       = pallet_info["n_boxes"]
instance["boxes_x_dim"]   = boxes_x_dim
instance["boxes_along_x"] = pallet_info["boxes_along_x"]
instance["boxes_along_y"] = pallet_info["boxes_along_y"]
instance["grip_size"]     = grip_size

result = instance.solve()
\end{lstlisting}
\vspace{0.5cm}

After the solver terminates, the Python code reads the MiniZinc output arrays
\texttt{group\_start}, \texttt{group\_len}, \texttt{drop\_order}, and
\texttt{plate}. These arrays describe the computed pallet layout and the
corresponding placement schedule.
